One hilarious line — a single line, 157 characters, with a twist, an agenda and snacks:

> My therapist told me to schedule my worries instead of spiraling, so now I have a full-blown panic attack every Tuesday at 4 p.m., with an agenda and snacks.

The program writes that single line to `/output/entry.txt` for make.fun's "One Line, Big Laugh" bounty. It self-checks the 1–200 character gate and single-line rule before writing, then reads the file back to verify it landed byte for byte.

## Run it

```sh
python3 main.py
```
